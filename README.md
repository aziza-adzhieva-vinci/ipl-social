## Objectif
Mettre en place un environnement DevOps avec GitHub Actions (CI) et appliquer le TDD.
Le projet contient une fonction TypeScript de validation d’email.

## Feature
Fichier : `src/emailValidator.ts` 

Règles vérifiées :
- l’email contient au moins un `@`
- pas d’espace
- texte avant et après le `@`
- le domaine contient un point `.` et le point n’est pas le dernier caractère

Tests : `tests/emailValidator.test.ts` (Jest)

## Lancer les tests
dans le terminal: 
npm test
